# REST API Practice — Express.js + EJS 🌐

A **full-stack REST API practice project** built with Node.js, Express.js, and EJS templating — demonstrating CRUD operations with server-side rendering.

## 🛠️ Tech Stack
- Node.js
- Express.js
- EJS (Embedded JavaScript templates)
- REST API conventions (GET, POST, PUT, DELETE)

## 🎯 Features
- Full CRUD operations via RESTful routes
- Server-side rendering with EJS templates
- Clean route structure following REST conventions
- Form handling with POST and method-override

## 📁 Project Structure
```
REST_CLASS/
├── index.js          # Express server and routes
├── views/
│   ├── index.ejs     # List all items
│   ├── show.ejs      # Show single item
│   ├── new.ejs       # Create new item form
│   └── edit.ejs      # Edit item form
└── public/           # Static assets
```

## 🔧 Setup & Run
```bash
npm install
node index.js
```
